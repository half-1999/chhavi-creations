# Chhavi's Creations Landing Page

1. Open `index.html` in a browser.
2. Replace `91XXXXXXXXXX` in `script.js` with the real WhatsApp number.
3. Replace the price placeholders in the `products` array.
4. Replace/add product images inside `assets/images/`.
5. Open `index.html` again.

This version uses the generated promotional visuals as starter assets.
